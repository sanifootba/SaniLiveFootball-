# SaniLiveFootball

A responsive starter website for a football streaming platform.

## Important
This starter does not contain pirated match feeds. Add only streams that you own or are licensed/authorized to distribute.

## Run
Open `index.html` in a browser, or deploy the folder to a static hosting service.
